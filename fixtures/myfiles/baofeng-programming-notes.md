# Baofeng Programming Notes (SAMPLE)

Cable: FTDI chip USB programming cable. Avoid Prolific chips — driver fights on Windows 11.

Software: CHIRP (free). Read from radio first, save a backup image, then write channels.

Repeaters to program: New England 2m/70cm repeaters and NOAA weather frequencies — load from the repeater directory export once downloaded.

Do not transmit on frequencies you are not licensed for.
