SDR++ receiver

In SDR++, enable the Rigctl Server module, select a VFO, enable tuning, and set Host to 127.0.0.1. Turn on Listen on startup. The hub uses port 4532 by default.

To open SDR++ from a frequency click, set sdrpp_executable to its absolute path in the laptop’s config.json and restart the hub.
